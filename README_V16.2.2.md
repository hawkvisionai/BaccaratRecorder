# Baccarat Platform Studio v16.2.2｜合併牌面輸入

## 本次更新

- 閒家使用同一組 A–K 按鈕，依序輸入起手兩張牌。
- 閒家兩張完成後，自動切換至莊家，同樣依序輸入兩張。
- 每張牌仍分別儲存在原本的 card_1、card_2、card_3 欄位。
- 起手牌與第三張補牌改為百家樂桌面式排列。
- 起手兩張完成後顯示綠色「＋點數」。
- 完成本局後，結果外框依勝方顯示：閒藍、莊紅、和綠。
- 點擊已輸入的牌可重新輸入，並自動清除受影響的補牌。

## 部署

本版不需執行新的 SQL。

覆蓋網站中的：

- `index.html`
- `app.js`
- `style.css`
