# Baccarat Platform Studio v16.6

## 本版重點

- 相機取景畫面新增閒、莊六格參考框。
- 前兩張為直向框，第三張為較寬的橫向框。
- 六格只作為寬鬆對位提示，不要求牌面完全貼齊框線。
- 畫面六格與 AI ROI 使用同一組百分比座標，實際裁切仍保留外圍容錯範圍。
- 保留 AI 辨識後人工目視確認，再按「下一局」儲存。
- 儲存成功後自動開啟下一局相機，上一局成功提示約 3 秒。

## 部署

覆蓋 GitHub：`index.html`、`app.js`、`style.css`。

本版不需要 SQL，也不需要重新部署 Edge Function。
